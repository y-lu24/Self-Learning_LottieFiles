## About 👩🏻‍💻 <a id="about"></a>
This repo documents Week 1 of my self-learning internship plan at Fanshawe College (IDP3). It includes two practice animations exported from After Effects using the LottieFiles plugin, embedded in a test HTML page to verify browser playback.

## Animations 🎬 <a id="animations"></a>
| File | Description |
|------|-------------|
| `Shapes.json` | Circle draw-on animation using Trim Paths — staggered concentric rings |
| `Text.json` | Per-letter text animation with position + bounce using shape layers converted from text |

Both animations were exported using the **LottieFiles for After Effects** plugin. The Feature Checker was used to verify Lottie compatibility before export.

## Tech 🛠️ <a id="tech"></a>
- After Effects 2025 (v26.0)
- LottieFiles for After Effects plugin
- `@lottiefiles/lottie-player` web component
- SASS (compiled to minified CSS)
- JS ES6 modules
